# Resume Description - Student Performance Analysis

## Short version (3 bullets)
**Student Performance Analysis | Microsoft Excel** *(Personal project, simulated data)*
- Analysed marks, attendance and results of 50 students using Excel formulas (IF, LOOKUP, RANK, COUNTIFS, AVERAGEIFS, INDEX-MATCH) and pivot-style summaries.
- Built an interactive dashboard with KPI cards and 6 charts showing pass rate (96%), grade distribution, subject averages and Top/Bottom 10 students.
- Found that students below 75% attendance averaged 54% vs 76% (correlation 0.70) and that Math was the weakest subject; recommended attendance alerts and extra Math classes.
